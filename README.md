# SYNTRIX pubblico

Avviare `build.ps1` per scaricare la release upstream più recente, applicare la patch pubblica e generare EXE e ZIP. Consultare [maintenance/README.md](maintenance/README.md) per requisiti e opzioni.

Con hide_cm attivo il connection manager si apre dalla tray; non viene mostrato alcun indicatore compatto. Nessuna installazione viene modificata automaticamente.
